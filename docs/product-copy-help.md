# Русские тексты и справка OyinQ

Проверено 16 сентября 2026 года на `master` поверх незакоммиченных изменений фильтров и общих коллекций.

## Карта потребителей

- Telegram: `TelegramBotProfile` (описание и команды), `TelegramBotProfileSetupService` (webhook/long polling), `TelegramUpdateHandler` (личный вход, контекст, выбор сообщества), `TelegramEntryText` (обзор/справка/подключение группы). Отдельного диалогового состояния регистрации здесь нет. Первое личное сообщение по-прежнему создаёт/обновляет участника через `ParticipantIdentityService`; кэмп регистрирует `CampRegistrationGate` в приложении.
- Mini App: `App`/`Navigation`, страницы сборов, создание/редактирование, состав и очередь, `PlayPanel`, каталог и фильтры, поиск BGG, личная коллекция/импорт, регистрация кэмпа, профиль/уведомления/календарь, общие пустые состояния и ошибки, админ-панель/рассылки.
- Общие сообщения: `GatheringPresentationService`, `NotificationDispatcher`, `TelegramNotificationTransport`; ограничения мутаций остаются в серверных сервисах. Исторические сохранённые уведомления не переписываются.
- Юридическое название политики, BGG, BG Stats, Telegram, настольные категории и точные технические сведения для администратора сохранены там, где они нужны. Кнопка к политике стала «О ваших данных».

## Термины и заметные правки

| Было | Стало | Контекст |
|---|---|---|
| Вишлист | Хотелки | Вкладка игр, кнопки, фильтр, уведомления и ошибки |
| Доступность | Коробка на кэмпе / Кто привезёт игру | Фильтр / карточка игры |
| Доступность обновлена | Сохранено | Обещание привезти игру |
| Параметры сбора | Когда и с кем играем | Форма создания |
| Ваша позиция в очереди | Ваше место в очереди | Лист ожидания |
| Черновик не был применён | Игры из этой загрузки не добавлены | Отмена импорта |
| Добавить в мои игры | Добавить в коллекцию | Личное владение |
| Сохранить уведомления | Сохранить настройки | Настройки сообщений |
| Сессия Telegram устарела… Mini App… | Не удалось подтвердить вход. Закройте приложение и снова откройте его из Telegram. | Ошибка входа |
| Сборы сохранят её снимок | В уже созданных сборах сведения о ней останутся | Удаление из клуба |
| История игр | Сыгранные партии | Подтверждённые партии в календаре |
| Собирают… | Новый сбор: «…» | Уведомление по хотелке |

«Сбор» — договорённость и запись; «партия» — сыгранная игра. «История сборов» включает отмены и сама по себе не подтверждает партию. «Могу привезти» и «Точно привезу» различаются намерением, личная коллекция не обещает коробку автоматически. В старой инструкции была ссылка на хотелки в профиле: в текущем UI они находятся только в **Игры → Хотелки**. Справка следует реализации; новый экран в профиль не добавлялся.

## Шаблоны и форматирование

`Integrations/Telegram/TelegramEntryText.cs` — единственный источник `/start` и `/help`, вынесенный из файла описания бота. Шесть тем справки: создание, запись/очередь, коллекция, хотелки/уведомления, кэмп, действия после игры. Все тела — раскрываемые цитаты; заголовки остаются видимыми. `RenderHelp` экранирует весь текст перед добавлением HTML. `TelegramEntryMessage` передаёт режим форматирования вместе с текстом: HTML только для справки; имена сообществ и `/menu` остаются plain text. Используется [HTML expandable blockquote Telegram](https://core.telegram.org/bots/api#html-style).

Итоговый `/start` — 293 символа, видимый `/help` — 2469. Тесты ограничивают их 550 и 3500 символами соответственно, проверяют структуру, шесть тем и экранирование. Команды уже регистрировались; `/help` сохранён в общем setup для обоих режимов запуска. Контекстные ссылки и глобальная личная коллекция не менялись.

`MiniApp/src/app/productCopy.ts` содержит общие подписи хотелок и Camp-обещаний. `ProductFooter` сохраняет BGG attribution и показывает «Автор бота — @MolonLabe» через существующий `ContactLink` → `telegram.openContact`, без сырого URL и отдельного превью. Фреймворк локализации не добавлялся.

Даты кэмпа: 25 сентября 19:00 UTC — 29 сентября 04:00 UTC, конец исключительный. Повторное присвоение, миграция данных и копирование старого снимка не нужны и не выполнялись.

На момент проверки последняя рабочая миграция — `20260914164813_ReliableGatheringPublication`. Новые локальные изменения общего чтения коллекций ещё не развёрнуты. После их развёртывания существующей связи достаточно для получения актуальной коллекции при новом запросе. Живое обновление каталога на сервере этой проверкой не подтверждалось.
